# Vehicle Management System

## About the Project
A web-based Vehicle Management System for managing vehicles, customers, bookings, and payments.

## Technologies Used
- HTML
- CSS
- JavaScript
- Java
- Spring Boot
- REST API
- MySQL
- Spring Data JPA
- Hibernate

## Main Modules
- Vehicle Management
- Customer Management
- Booking Management
- Payment Management

## Project Architecture

Frontend → REST API → Spring Boot → Service → Repository → MySQL

## Features
- Add and manage vehicles
- Add and manage customers
- Create bookings
- Manage payments
- Store data in MySQL
- Web-based user interface

## How to Run
1. Start MySQL using XAMPP.
2. Open the backend project in IntelliJ IDEA.
3. Run the Spring Boot application.
4. Open the frontend in a browser.
5. Use the website to manage vehicles, customers, bookings, and payments.
